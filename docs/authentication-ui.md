# 管理画面ログインUI

## 目的

テナントと運営管理者のログイン画面を、各管理画面のデザイントークンに沿った一貫した認証UIへ統一する。管理画面本体のナビゲーションは未ログイン時に表示せず、認証に必要な情報だけへ集中させる。

## 画面構成

- 共通の認証専用レイアウトとCSSを使用する。
- 左側にCommunity Hubの役割説明、右側にログインカードを配置する。
- テナントは緑とライム、運営管理者は紫をアクセントに使用する。
- メールアドレス、パスワード、ログイン状態保持、送信ボタンを同じ構造にする。
- flashは`notice`をステータス、`alert`をエラーとして表示する。
- 狭い画面では説明領域を縮小し、1カラムで表示する。

## 対象

- `Tenant::SessionsController`
- `Admin::SessionsController`
- `layouts/authentication`
- Tenant/AdminのDeviseログインビュー
- `authentication.css`

認証処理、パラメータ、ログイン後・ログアウト後の遷移先は変更しない。

## 検証

- 両ログインURLが認証専用レイアウトで表示される。
- HTML内にインライン`style`および入れ子の`html/body`が存在しない。
- 適切なフォーム送信先、autocomplete、必須属性、flashのroleを維持する。
- Backend全体のテストを実行する。
