# ER定義

## 役割

`docs/er` 配下の領域別文書を、テーブル構造の正本とする。ER文書には、テーブル、カラム、型、NULL可否、初期値、主キー、外部キー、一意制約、CHECK制約、関連およびインデックスを記載する。

業務上の責務、処理フロー、状態遷移、認可、計算方法、設計判断は `docs/architecture` 配下を正本とする。ER文書ではデータ整合性の説明に必要な範囲だけを記載し、業務仕様を重複して定義しない。
