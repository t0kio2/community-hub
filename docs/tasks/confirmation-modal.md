# 破壊的操作の確認モーダル

## 目的

テナント画面と運営管理画面の削除確認を、ブラウザ標準の`confirm()`ではなく共通デザインのモーダルへ統一する。

## 変更範囲

- 共通の`dialog`パーシャル、スタイル、送信制御
- 拠点削除とテナントアカウント削除のフォーム
- 削除確認を持つ画面のコントローラーテスト

## 実装方針

- 対象フォームへ`data-confirm-message`を設定する。
- 共通スクリプトがフォーム送信を保留し、確認後に同じフォームを再送信する。
- キャンセル、Escapeキー、背景クリックでは送信しない。
- 今後の破壊的操作も同じ属性だけでモーダルを利用できるようにする。
- 拠点一覧では編集を枠付きボタン、削除を赤い文字のみの操作として区別する。

## 検証

対象フォームと共通モーダルがHTMLへ出力されることをテストし、Docker Composeで全Backendテストを実行する。
